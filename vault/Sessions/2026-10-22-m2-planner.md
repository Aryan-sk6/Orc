# 2026-10-22: M2 AgentAdapter, FakeAgentAdapter, `orc plan`, `orc check-setup`

## Goal
Complete M2 from [[Roadmap]]: the `AgentAdapter` interface and `FakeAgentAdapter` (moved here by [[0007-shared-planner-prompt-and-api-key]]), the planner as one shared prompt file run through the adapter, and `orc check-setup`.

## Done
- **`src/agents/`:** `AgentAdapter` (`runTurn` → `{sessionId, outcome, text, costUsd per turn, errors}`, plus `close`), SDK-agnostic. `FakeAgentAdapter` replays scripted turns, records requests and fails loudly on a mismatch or when the script runs out. A JSON fake-script loader supports `textFile`. `createAdapter` picks the adapter from config. New config key `fakeScript`.
- **Plan format** in `src/vault/plan.ts`: strict markdown, parsed and validated (env vars, docs, workstreams, `needs`, cycles, shared ownership), plus a generated `task-graph.md` with a mermaid chart. See [[0008-plan-as-strict-markdown]].
- **Shared prompt** `kit/prompts/planner.md` (ships in the package). The CLI-only reply protocol is in `src/planner/protocol.ts`.
- **`orc plan <idea.md>`:** questions turn → terminal Q&A (Enter accepts the default, `--defaults` accepts all, EOF falls back to defaults) → `plan/questions.md` → plan turn in the same session → validate → up to `retries.maxPerTask` repair turns → atomic writes plus a LOG line from session `planner`. Each turn gets the remaining `maxBudgetUsd`. It refuses to overwrite a plan without `--force`, and checks this before any model call.
- **`orc check-setup`:** `ANTHROPIC_API_KEY` must be in the environment. Plan env vars may be in the environment, `.env.local` or `.env`. Docs must exist and be non-empty in `vault/docs/`. Values are never printed. Exits 1 when something is missing. `--json` is available.
- `CliIO` gained `env` and `readLine` (a lazy readline, so commands that never ask don't hold stdin open).
- `npm run demo:plan` runs the todo fixture end to end with the fake adapter, writing into `.demo/` (gitignored).
- 157 tests pass (up from 94). Typecheck, lint and build are clean. I also ran the built binary with piped stdin.

## Problems hit
- **Biome 2.6 formats Markdown** and broke it: `---`/`tags:` frontmatter became `## tags:` (even inside a fenced example in the prompt), and it indented `<<<orc-end>>>` markers so they no longer matched. `biome.json` now excludes `**/*.md`. Lesson: after `npm run format`, check `git status` for `.md` changes.
- `fs.readdir({recursive})` together with `Dirent.parentPath` needs Node 20.12+, but `engines` is `>=20`, so `readPlanFiles` walks directories by hand.
